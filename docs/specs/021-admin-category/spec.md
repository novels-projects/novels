# Feature Specification: การจัดการหมวดหมู่โดย Admin

**Feature ID:** `021-admin-category`
**Status:** Draft
**Source:** `docs/SRS.md`

## 1. Goal

ให้ Admin ดู เพิ่ม แก้ไข และลบหมวดหมู่ของนิยายได้ตามเงื่อนไขของระบบ โดยมีการตรวจสอบข้อมูลก่อนดำเนินการ

## 2. Scope

### In Scope

* ดูรายการหมวดหมู่ทั้งหมด
* เพิ่มหมวดหมู่
* แก้ไขหมวดหมู่
* ลบหมวดหมู่ตามเงื่อนไขของระบบ
* ตรวจสอบข้อมูลก่อนดำเนินการกับหมวดหมู่

### Out of Scope

* การเรียกดูนิยายตามหมวดหมู่
* การจัดการหมวดหมู่ของนิยายโดยนักเขียน
* การจัดการนิยายโดย Admin
* การจัดการบัญชีผู้ใช้งานโดย Admin

## 3. Requirements

### R-CAT-01 — ดูรายการหมวดหมู่

ระบบต้องให้ Admin ดูรายการหมวดหมู่ทั้งหมดได้

**Traceability:** `FR-CAT-01`

### R-CAT-02 — เพิ่มหมวดหมู่

ระบบต้องให้ Admin เพิ่มหมวดหมู่ได้

**Traceability:** `FR-CAT-02`

### R-CAT-03 — แก้ไขหมวดหมู่

ระบบต้องให้ Admin แก้ไขหมวดหมู่ได้

**Traceability:** `FR-CAT-03`

### R-CAT-04 — ลบหมวดหมู่

ระบบต้องให้ Admin ลบหมวดหมู่ได้ตามเงื่อนไขของระบบ

**Traceability:** `FR-CAT-04`

### R-CAT-05 — ตรวจสอบข้อมูลก่อนดำเนินการ

ระบบต้องตรวจสอบข้อมูลก่อนดำเนินการกับหมวดหมู่

**Traceability:** `FR-CAT-05`

## 4. Acceptance Criteria

* **AC-CAT-01** เมื่อ Admin เปิดดูรายการหมวดหมู่ ระบบต้องแสดงหมวดหมู่ทั้งหมด
* **AC-CAT-02** เมื่อ Admin เพิ่มหมวดหมู่ ระบบต้องเพิ่มหมวดหมู่นั้นเข้ากับรายการหมวดหมู่ของระบบ
* **AC-CAT-03** เมื่อ Admin แก้ไขหมวดหมู่ ระบบต้องบันทึกข้อมูลที่แก้ไขของหมวดหมู่นั้น
* **AC-CAT-04** เมื่อ Admin ลบหมวดหมู่ ระบบต้องลบหมวดหมู่นั้นเมื่อเป็นไปตามเงื่อนไขของระบบ
* **AC-CAT-05** เมื่อมีการดำเนินการกับหมวดหมู่ ระบบต้องตรวจสอบข้อมูลก่อนดำเนินการ

## 5. Constraints

* การดำเนินการเกี่ยวกับหมวดหมู่ต้องเป็นไปตามสิทธิ์ของ Admin
* หมวดหมู่ที่ยังถูกใช้งานอยู่ในนิยายต้องพิจารณาเงื่อนไขของระบบก่อนดำเนินการ
* การเรียกดูนิยายตามหมวดหมู่อยู่ในขอบเขตของ `005-browse-category`
* การจัดการหมวดหมู่ของนิยายโดยนักเขียนอยู่ในขอบเขตของ `013-writer-novel-management`
* การจัดการนิยายโดย Admin อยู่ในขอบเขตของ `025-admin-novel-management`

## 7. Open Questions

* ข้อมูลของหมวดหมู่ที่ระบบกำหนดให้บังคับกรอกมีอะไรบ้าง
* ระบบตรวจสอบข้อมูลหมวดหมู่ก่อนดำเนินการอย่างไร เช่น ต้องไม่ซ้ำกับหมวดหมู่ที่มีอยู่หรือไม่
* เงื่อนไขของระบบที่กำหนดไว้สำหรับการลบหมวดหมู่คืออะไร และมีผลต่อนิยายที่ใช้หมวดหมู่นั้นอย่างไร
* เมื่อหมวดหมู่ถูกลบหรือถูกแก้ไขชื่อ ผลต่อนิยายที่เคยจัดอยู่ในหมวดหมูะนั้นเป็นอย่างไร
