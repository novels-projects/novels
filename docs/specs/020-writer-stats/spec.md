# Feature Specification: ข้อมูลสถิติของนิยายสำหรับนักเขียน

**Feature ID:** `020-writer-stats`
**Status:** Draft
**Source:** `docs/SRS.md`

## 1. Goal

ให้นักเขียนดูข้อมูลสถิติของนิยายตามความสามารถที่มีอยู่ในระบบปัจจุบัน โดยดูได้เฉพาะนิยายที่ตนมีสิทธิ์เข้าถึง

## 2. Scope

### In Scope

* แสดงข้อมูลสถิติของนิยายตามความสามารถที่มีอยู่ในระบบปัจจุบัน
* แสดงข้อมูลสถิติแก่นักเขียนของนิยายที่ตนเองมีสิทธิ์เข้าถึง

### Out of Scope

* การจัดการนิยาย ตอน ฉาก และตัวเลือก
* การเผยแพร่นิยาย
* การดูตัวอย่างนิยาย
* การดูข้อมูลของผู้ใช้งานคนอื่น
* การจัดการข้อมูลสถิติโดย Admin

## 3. Requirements

### R-STATS-01 — แสดงข้อมูลสถิติของนิยาย

ระบบต้องแสดงข้อมูลสถิติของนิยายตามความสามารถที่มีอยู่ในระบบปัจจุบัน

**Traceability:** `FR-STATS-01`

### R-STATS-02 — จำกัดสิทธิ์การดูข้อมูลสถิติ

ระบบต้องแสดงข้อมูลสถิติให้แก่นักเขียนของนิยายที่ตนเองมีสิทธิ์เข้าถึง

**Traceability:** `FR-STATS-02`

## 4. Acceptance Criteria

* **AC-STATS-01** เมื่อนักเขียนเปิดดูข้อมูลสถิติของนิยาย ระบบต้องแสดงข้อมูลสถิติตามความสามารถที่มีอยู่ในระบบปัจจุบัน
* **AC-STATS-02** เมื่อนักเขียนเปิดดูข้อมูลสถิติ ระบบต้องแสดงข้อมูลของนิยายที่นักเขียนมีสิทธิ์เข้าถึงเท่านั้น

## 5. Constraints

* นักเขียนสามารถดูข้อมูลสถิติได้เฉพาะนิยายของตนเอง
* ข้อมูลสถิติที่แสดงขึ้นอยู่ภายใต้ความสามารถที่มีอยู่ในระบบปัจจุบัน
* SRS ยังไม่ได้กำหนดค่าเชิงตัวเลขสำหรับข้อกำหนดด้านประสิทธิภาพของข้อมูลสถิติ
* การดูตัวอย่างนิยายอยู่ในขอบเขตของ `019-preview`
* การจัดการนิยายอยู่ในขอบเขตของ `013-writer-novel-management`

## 7. Open Questions

* ข้อมูลสถิติใดบ้างที่ระบบต้องแสดง และคำนวณจากข้อมูลส่วนใดของระบบ
* ข้อมูลสถิติที่มีอยู่ในระบบปัจจุบันครอบคลุมข้อมูลระดับใดบ้าง เช่น ระดับนิยาย ตอน ฉาก หรือตัวเลือก
* ระบบจะแสดงข้อมูลสถิติของนิยายที่ยังไม่ได้เผยแพร่หรือไม่
* ช่วงเวลาและความถี่ในการอัปเดตข้อมูลสถิติเป็นอย่างไร
* มีการส่งออกข้อมูลสถิติของนิยายหรือไม่ และรูปแบบใด
