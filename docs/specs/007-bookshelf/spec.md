# Feature Specification: เพิ่มนิยายเข้าชั้นหนังสือ

**Feature ID:** `007-bookshelf`
**Status:** Draft
**Source:** `docs/SRS.md`

## 1. Goal

ให้ Reader สามารถเพิ่มนิยายที่สนใจลงในชั้นหนังสือ และนำนิยายออกจากชั้นหนังสือได้

## 2. Scope

### In Scope

* เพิ่มนิยายลงชั้นหนังสือ
* นำนิยายออกจากชั้นหนังสือ

### Out of Scope

* การค้นหานิยาย
* การเรียกดูนิยายตามหมวดหมู่
* รายละเอียดนิยาย
* การอ่านนิยาย
* การบันทึกและอ่านต่อจากตำแหน่งเดิม
* แผนผังการอ่าน
* การติดตามนักเขียน
* การแจ้งเตือน
* การจัดการนิยายของ Writer
* การจัดการของ Admin

## 3. Requirements

### R-BOOK-01 — เพิ่มนิยายลงชั้นหนังสือ

ระบบต้องให้ Reader เพิ่มนิยายลงในชั้นหนังสือของตนเองได้

**Traceability:** `FR-FOLLOW-01`

### R-BOOK-02 — นำนิยายออกจากชั้นหนังสือ

ระบบต้องให้ Reader นำนิยายออกจากชั้นหนังสือของตนเองได้

**Traceability:** `FR-FOLLOW-02`

## 4. Acceptance Criteria

* **AC-BOOK-01** เมื่อ Reader เพิ่มนิยายลงชั้นหนังสือ ระบบต้องเพิ่มนิยายเรื่องนั้นลงในชั้นหนังสือของ Reader
* **AC-BOOK-02** เมื่อนิยายอยู่ในชั้นหนังสือของ Reader ระบบต้องสามารถนำเอานิยายเรื่องนั้นออกจากชั้นหนังสือได้

## 5. Constraints

* การเพิ่มหรือนำนิยายออกจากชั้นหนังสือเป็นข้อมูลของ Reader แต่ละคน
* การเพิ่มหรือนำนิยายออกจากชั้นหนังสือต้องไม่เปลี่ยนแปลงข้อมูลของนิยาย
* การแจ้งเตือนที่เกี่ยวข้องกับนิยายในชั้นหนังสืออยู่ในขอบเขตของ `FR-NOTI-03` และไม่รวมอยู่ใน feature นี้
