# Feature Specification: การดูตัวอย่างนิยายของนักเขียน

**Feature ID:** `019-preview`
**Status:** Draft
**Source:** `docs/SRS.md`

## 1. Goal

ให้นักเขียนดูตัวอย่างนิยายของตนเองก่อนเผยแพร่ได้ โดยการดูตัวอย่างต้องแยกจากสถานะการอ่านของผู้ใช้งานทั่วไป

## 2. Scope

### In Scope

* นักเขียนดูตัวอย่างนิยายของตนเองก่อนเผยแพร่
* แยกการดูตัวอย่างออกจากสถานะการอ่านของผู้ใช้งานทั่วไป

### Out of Scope

* การเผยแพร่นิยาย
* การกำหนดฉากจบ
* การแสดงโครงสร้างเนื้อเรื่องของนักเขียน
* การบันทึกตำแหน่งการอ่าน
* การดูข้อมูลสถิติของนิยาย

## 3. Requirements

### R-PREVIEW-01 — ดูตัวอย่างนิยายก่อนเผยแพร่

ระบบต้องให้นักเขียนดูตัวอย่างนิยายก่อนเผยแพร่ได้

**Traceability:** `FR-PREVIEW-01`

### R-PREVIEW-02 — แยกการดูตัวอย่างจากสถานะการอ่าน

ระบบต้องแยกการดูตัวอย่างออกจากสถานะการอ่านของผู้ใช้งานทั่วไป

**Traceability:** `FR-PREVIEW-02`

### R-PREVIEW-03 — การดูตัวอย่างไม่เปลี่ยนสถานะการอ่าน

การอ่านจากตัวอย่างหรือ Preview ของนักเขียนต้องไม่เปลี่ยนสถานะการอ่านของผู้ใช้งานทั่วไป

**Traceability:** `FR-PROG-03`

## 4. Acceptance Criteria

* **AC-PREVIEW-01** เมื่อนักเขียนเปิดดูตัวอย่างนิยายของตนเองก่อนเผยแพร่ ระบบต้องแสดงเนื้อหาของนิยายให้นักเขียน
* **AC-PREVIEW-02** เมื่อการดูตัวอย่างเกิดขึ้น สถานะการอ่านของผู้ใช้งานทั่วไปต้องไม่ถูกเปลี่ยนแปลง
* **AC-PREVIEW-03** เมื่อนักเขียนอ่านนิยายผ่านการดูตัวอย่าง ระบบต้องไม่บันทึกข้อมูลการอ่านของผู้ใช้งานทั่วไป

## 5. Constraints

* การดูตัวอย่างเป็นการใช้งานสำหรับนักเขียนของนิยายเรื่องนั้น
* การดูตัวอย่างไม่ทำให้ผู้ใช้งานทั่วไปเข้าถึงเนื้อหาที่ยังไม่ได้เลือกเผยแพร่
* การเผยแพร่นิยายอยู่ในขอบเขตของ `018-publish`
* การบันทึกและอ่านต่อจากตำแหน่งที่อ่านค้างไว้อยู่ในขอบเขตของ `002-reading-progress`
* การแสดงโครงสร้างเนื้อเรื่องของนักเขียนอยู่ในขอบเขตของ `017-structure`

## 7. Open Questions

* นักเขียนสามารถดูตัวอย่างนิยายที่ยังไม่ได้เผยแพร่ในขอบเขตใดได้บ้าง
  * **ข้อยุติจากการตรวจสอบระบบจริง:** นักเขียนเจ้าของเรื่องสามารถดูตัวอย่างได้ทุกตอนและทุกฉาก แม้ยังอยู่ในสถานะ `draft`
* เมื่อการดูตัวอย่างนิยายที่ยังไม่ได้เผยแพร่ ระบบต้องแสดงเนื้อหาส่วนใดบ้าง และต้องคำนึงถึงสถานะการเผยแพร่ของตอนและฉากอย่างไร
  * **ข้อยุติจากการตรวจสอบระบบจริง:** แสดงเนื้อหาและตัวเลือกครบถ้วนเสมือนโหมดอ่านจริง โดยบายพาสการตรวจสถานะ `published` เฉพาะเจ้าของเรื่อง
* บทบาทอื่นนอกเหนือจากนักเขียนของนิยายเรื่องนั้นสามารถใช้การดูตัวอย่างได้หรือไม่
  * **ข้อยุติจากการตรวจสอบระบบจริง:** ผู้ใช้อื่นและ Guest ไม่สามารถเข้าถึง Preview ของนิยายที่ยังไม่เผยแพร่ได้
* การดูตัวอย่างสามารถเลือกทางเลือกและเดินทางต่อได้หรือไม่ และมีผลต่อโครงสร้างเนื้อเรื่องอย่างไร
  * **ข้อยุติจากการตรวจสอบระบบจริง:** สามารถคลิกเลือก Choice เพื่อทดสอบการเดินเรื่องได้ตามปกติ แต่ไม่มีผลกระทบต่อโครงสร้างเนื้อเรื่องหรือการบันทึกข้อมูล
* สถานะการอ่านของผู้ใช้งานทั่วไปที่ต้องไม่ถูกเปลี่ยนแปลงรวมถึงข้อมูลใดบ้าง
  * **ข้อยุติจากการตรวจสอบระบบจริง:** ไม่มีการบันทึกหรือเปลี่ยนแปลง `reading_progress`, `user_scene_history`, `user_choice_history`, `user_endings` และไม่นับยอด View เพิ่มในสถิติ
