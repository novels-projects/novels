# Feature Specification: การสมัครและจัดการสิทธิ์นักเขียน

**Feature ID:** `012-writer-application`
**Status:** Draft
**Source:** `docs/SRS.md`

## 1. Goal

ให้ผู้ใช้งานสมัครเป็นนักเขียน และให้ Admin ตรวจสอบ อนุมัติหรือจัดการคำขอตามสถานะที่ระบบกำหนด จนได้รับสิทธิ์นักเขียน

## 2. Scope

### In Scope

* สมัครเป็นนักเขียน
* ตรวจสอบคำขอสมัครนักเขียน
* อนุมัติหรือจัดการคำขอสมัครนักเขียนตามสถานะที่ระบบกำหนด
* กำหนดสิทธิ์นักเขียนให้ผู้ใช้งานที่ได้รับการอนุมัติ

### Out of Scope

* การจัดการนิยาย ตอน ฉาก และตัวเลือกของนักเขียน
* การจัดการข้อมูลบัญชีผู้ใช้งานโดย Admin
* การจัดการหมวดหมู่โดย Admin

## 3. Requirements

### R-WRITER-01 — สมัครเป็นนักเขียน

ระบบต้องให้ผู้ใช้งานสมัครเป็นนักเขียนได้

**Traceability:** `FR-WRITER-01`

### R-WRITER-02 — ตรวจสอบคำขอสมัครนักเขียน

ระบบต้องให้ Admin ตรวจสอบคำขอสมัครนักเขียนได้

**Traceability:** `FR-WRITER-02`

### R-WRITER-03 — อนุมัติหรือจัดการคำขอสมัครนักเขียน

ระบบต้องให้ Admin อนุมัติหรือจัดการคำขอสมัครนักเขียนตามสถานะที่ระบบกำหนด

**Traceability:** `FR-WRITER-03`

### R-WRITER-04 — กำหนดสิทธิ์นักเขียน

เมื่อคำขอสมัครนักเขียนได้รับการอนุมัติ ระบบต้องกำหนดสิทธิ์นักเขียนให้แก่ผู้ใช้งานที่สมัคร

**Traceability:** `FR-WRITER-04`

## 4. Acceptance Criteria

* **AC-WRITER-01** เมื่อผู้ใช้งานสมัครเป็นนักเขียน ระบบต้องรับคำขอของผู้ใช้งานนั้น
* **AC-WRITER-02** เมื่อ Admin เปิดดูคำขอสมัครนักเขียน ระบบต้องแสดงคำขอที่ส่งเข้ามา
* **AC-WRITER-03** เมื่อ Admin อนุมัติหรือจัดการคำขอสมัครนักเขียน ระบบต้องเปลี่ยนสถานะของคำขอนั้นตามการดำเนินการ
* **AC-WRITER-04** เมื่อคำขอสมัครนักเขียนได้รับการอนุมัติ ระบบต้องกำหนดสิทธิ์นักเขียนให้แก่ผู้ใช้งานที่สมัคร

## 5. Constraints

* การสมัครเป็นนักเขียนและการจัดการคำขอต้องเป็นไปตามบทบาทที่ระบบกำหนด
* นักเขียนสามารถใช้ความสามารถของ Reader ได้ทั้งหมด
* การสมัครสมาชิกและเข้าสู่ระบบอยู่ในขอบเขตของ `009-authentication`
* การจัดการนิยายของนักเขียนอยู่ในขอบเขตของ `013-writer-novel-management`
* ความสนใจของนักเขียนที่เลือกตอนยื่นคำขอ (`category_ids` / `genres`) ต้องมีจำนวน 3-5 รายการ และ Backend ต้องตรวจสอบค่านี้ (`VAL-07`)
* รูปอวตารที่แนบมากับคำขอต้องไม่เกิน 5MB และเป็นไฟล์ภาพประเภท JPEG, PNG หรือ WebP เท่านั้น (`VAL-09`, `VAL-10`)
* การตรวจสอบข้อมูลขาเข้าเป็นไปตาม `FR-VALID-01` ซึ่งเป็นข้อกำหนดกลางตาม `docs/SRS.md` §3.1.17 — กฎ `VAL-01` ถึง `VAL-11` เป็นแหล่งอ้างอิงค่ากฎตามเดิม

## 7. Open Questions

* ข้อมูลใดบ้างที่ผู้ใช้งานต้องกรอกในการสมัครเป็นนักเขียน และมีข้อมูลใดที่ระบบกำหนดให้บังคับกรอก
  * **ข้อยุติจากการตรวจสอบระบบจริง:** กรอกข้อมูลประวัติ ผลงานที่ผ่านมา หมวดหมู่ความสนใจ (3-5 หมวดหมู่ ตามกฎ VAL-07) และแนบไฟล์เอกสาร/ภาพยืนยันตัวตนส่งไปจัดเก็บที่ MinIO
* คำขอสมัครนักเขียนมีสถานะใดบ้าง และสถานะใดที่อนุญาตให้ Admin ดำเนินการได้
  * **ข้อยุติจากการตรวจสอบระบบจริง:** สถานะได้แก่ `pending`, `approved`, `rejected` โดย Admin ดำเนินการอนุมัติหรือปฏิเสธได้เฉพาะคำขอที่อยู่ในสถานะ `pending`
* เมื่อ Admin ไม่อนุมัติคำขอ ระบบต้องแจ้งผลการจัดการแก่ผู้สมัครอย่างไร
  * **ข้อยุติจากการตรวจสอบระบบจริง:** ส่ง In-app Notification แจ้งเตือนผู้ใช้ พร้อมระบุเหตุผลที่ถูกปฏิเสธ
* ผู้ใช้งานที่ถูกปฏิเสธสามารถยื่นคำขอใหม่ได้หรือไม่ และมีเงื่อนไขอย่างไร
  * **ข้อยุติจากการตรวจสอบระบบจริง:** สามารถแก้ไขข้อมูลและยื่นคำขอสมัครใหม่ได้
