# Feature Specification: การกำหนดฉากจบและการเผยแพร่นิยาย

**Feature ID:** `018-publish`
**Status:** Draft
**Source:** `docs/SRS.md`

## 1. Goal

ให้นักเขียนกำหนดฉากจบของเส้นทางนิยาย และเผยแพร่นิยายของตนเองได้เมื่อผ่านการตรวจสอบเงื่อนไขของโครงสร้างเนื้อเรื่องตามที่ระบบกำหนด

## 2. Scope

### In Scope

* กำหนดฉากจบของเส้นทางนิยาย
* ตรวจสอบเงื่อนไขของโครงสร้างเนื้อเรื่องก่อนเผยแพร่
* แจ้งเตือนนักเขียนเมื่อโครงสร้างเนื้อเรื่องไม่ผ่านเงื่อนไขที่จำเป็นต่อการเผยแพร่
* เลือกเผยแพร่และยกเลิกการเผยแพร่นิยายของตนเอง
* จัดการสถานะของนิยายตามสถานะที่ระบบกำหนด

### Out of Scope

* การแสดงโครงสร้างเนื้อเรื่องและการตรวจสอบความสัมพันธ์ของฉากและตัวเลือก
* การกำหนดฉากเริ่มต้น
* การจัดการหมวดหมู่ของนิยาย
* การดูตัวอย่างนิยายก่อนเผยแพร่ของนักเขียน
* การจัดการสถานะของนิยายโดย Admin

## 3. Requirements

### R-PUBLISH-01 — กำหนดฉากจบ

ระบบต้องให้นักเขียนกำหนดฉากจบของเส้นทางนิยายได้

**Traceability:** `FR-PUBLISH-01`

### R-PUBLISH-02 — ตรวจสอบเงื่อนไขก่อนเผยแพร่

ระบบต้องตรวจสอบเงื่อนไขของโครงสร้างเนื้อเรื่องก่อนเผยแพร่ตามที่ระบบกำหนด

**Traceability:** `FR-PUBLISH-02`

### R-PUBLISH-03 — แจ้งเตือนเมื่อโครงสร้างเนื้อเรื่องไม่ผ่านเงื่อนไข

ระบบต้องแจ้งเตือนนักเขียนเมื่อโครงสร้างเนื้อเรื่องไม่ผ่านเงื่อนไขที่จำเป็นต่อการเผยแพร่

**Traceability:** `FR-PUBLISH-03`

### R-PUBLISH-04 — เลือกเผยแพร่นิยาย

ระบบต้องไม่เผยแพร่นิยายจนกว่านักเขียนจะเลือกเผยแพร่ตามการทำงานของระบบ

**Traceability:** `FR-PUBLISH-04`

### R-PUBLISH-05 — จัดการสถานะของนิยาย

ระบบต้องจัดการสถานะของนิยายตามสถานะที่ระบบกำหนด

**Traceability:** `FR-PUBLISH-05`

### R-NOVEL-04 — เลือกเผยแพร่นิยายของตนเอง

ระบบต้องให้นักเขียนเลือกเผยแพร่นิยายของตนเองได้

**Traceability:** `FR-NOVEL-04`

### R-NOVEL-05 — ยกเลิกการเผยแพร่นิยายของตนเอง

ระบบต้องให้นักเขียนยกเลิกการเผยแพร่นิยายของตนเองได้ตามความสามารถของระบบ

**Traceability:** `FR-NOVEL-05`

## 4. Acceptance Criteria

* **AC-PUBLISH-01** เมื่อนักเขียนกำหนดฉากจบของเส้นทางนิยาย ระบบต้องบันทึกฉากนั้นเป็นฉากจบของนิยาย
* **AC-PUBLISH-02** เมื่อนักเขียนขอเผยแพร่นิยาย ระบบต้องตรวจสอบเงื่อนไขของโครงสร้างเนื้อเรื่องก่อนตามที่ระบบกำหนด
* **AC-PUBLISH-03** เมื่อโครงสร้างเนื้อเรื่องไม่ผ่านเงื่อนไขที่จำเป็นต่อการเผยแพร่ ระบบต้องแจ้งเตือนนักเขียนเกี่ยวกับเงื่อนไขที่ไม่ผ่าน
* **AC-PUBLISH-04** เมื่อนักเขียนยังไม่ได้เลือกเผยแพร่นิยาย ระบบต้องไม่เผยแพร่นิยายเรื่องนั้น
* **AC-PUBLISH-05** เมื่อสถานะของนิยายเปลี่ยนแปลง ระบบต้องจัดการสถานะของนิยายตามสถานะที่ระบบกำหนด
* **AC-PUBLISH-06** เมื่อนักเขียนเลือกเผยแพร่นิยายของตนเอง ระบบต้องเผยแพร่นิยายเรื่องนั้น
* **AC-PUBLISH-07** เมื่อนักเขียนยกเลิกการเผยแพร่นิยายของตนเอง ระบบต้องยกเลิกการเผยแพร่นิยายเรื่องนั้นตามความสามารถของระบบ

## 5. Constraints

* นักเขียนเป็นผู้เลือกเผยแพร่นิยายของตนเอง
* นิยายที่ยังไม่ได้เลือกเผยแพร่ต้องไม่แสดงต่อผู้ใช้งานทั่วไป
* นักเขียนสามารถเลือกเผยแพร่และยกเลิกการเผยแพร่ได้เฉพาะนิยายของตนเอง
* การตรวจสอบความสัมพันธ์และความถูกต้องของโครงสร้างเนื้อเรื่องอยู่ในขอบเขตของ `017-structure`
* การกำหนดฉากเริ่มต้นอยู่ในขอบเขตของ `017-structure`
* การดูตัวอย่างนิยายก่อนเผยแพร่อยู่ในขอบเขตของ `019-preview`
* การจัดการหมวดหมู่ของนิยายอยู่ในขอบเขตของ `013-writer-novel-management`
* การจัดการสถานะของนิยายโดย Admin อยู่ในขอบเขตของ `025-admin-novel-management`

## 7. Open Questions

* ประเภทของฉากจบที่ระบบรองรับมีอะไรบ้าง และต้องบันทึกข้อมูลใดบ้างของฉากจบ
* นิยายหนึ่งเรื่องต้องมีฉากจบอย่างน้อยกี่ฉาก
* ต้องมีฉากเริ่มต้นเพื่อให้เผยแพร่นิยายได้หรือไม่ เนื่องจาก `FR-STRUCT-10` ระบุว่าการเผยแพร่นิยายไม่จำเป็นต้องมีการกำหนดฉากเริ่มต้น
* เงื่อนไขของโครงสร้างเนื้อเรื่องที่ต้องตรวจสอบก่อนเผยแพร่มีอะไรบ้าง และเงื่อนไขใดทำให้ไม่ผ่านการตรวจสอบ
* สถานะของนิยายที่ระบบกำหนดมีสถานะใดบ้าง และสถานะแต่ละสถานะส่งผลต่อการแสดงผลต่อผู้ใช้งานอย่างไร
* เมื่อนักเขียนยกเลิกการเผยแพร่นิยายแล้วเผยแพร่อีกครั้ง ต้องผ่านการตรวจสอบเงื่อนไขใหม่หรือไม่
* นิยายที่อยู่ระหว่างการถูกระงับการเผยแพร่โดย Admin อยู่ในขอบเขตของการจัดการสถานะของนักเขียนหรือไม่
