# Feature Specification: การจัดการผู้ใช้งานโดย Admin

**Feature ID:** `022-admin-user-management`
**Status:** Draft
**Source:** `docs/SRS.md`

## 1. Goal

ให้ Admin ดูข้อมูลผู้ใช้งานและจัดการบัญชีผู้ใช้งานตามความสามารถของระบบ โดยมีการตรวจสอบสิทธิ์ของ Admin ก่อนดำเนินการ

## 2. Scope

### In Scope

* ดูข้อมูลผู้ใช้งานตามสิทธิ์ที่กำหนด
* จัดการบัญชีผู้ใช้งานตามความสามารถของระบบ
* ตรวจสอบสิทธิ์ของ Admin ก่อนดำเนินการกับข้อมูลผู้ใช้งาน

### Out of Scope

* การจัดการข้อมูลบัญชีผู้ใช้งานด้วยตนเอง
* การสมัครสมาชิกและเข้าสู่ระบบ
* การจัดการคำขอสมัครนักเขียน
* การจัดการหมวดหมู่และนิยายโดย Admin
* การบันทึก Audit Log

## 3. Requirements

### R-ADMINUSER-01 — ดูข้อมูลผู้ใช้งาน

ระบบต้องให้ Admin ดูข้อมูลผู้ใช้งานตามสิทธิ์ที่กำหนดได้

**Traceability:** `FR-ADMINUSER-01`

### R-ADMINUSER-02 — จัดการบัญชีผู้ใช้งาน

ระบบต้องให้ Admin จัดการบัญชีผู้ใช้งานตามความสามารถของระบบได้

**Traceability:** `FR-ADMINUSER-02`

### R-ADMINUSER-03 — ตรวจสอบสิทธิ์ของ Admin

ระบบต้องตรวจสอบสิทธิ์ของ Admin ก่อนดำเนินการกับข้อมูลผู้ใช้งาน

**Traceability:** `FR-ADMINUSER-03`

## 4. Acceptance Criteria

* **AC-ADMINUSER-01** เมื่อ Admin เปิดดูข้อมูลผู้ใช้งาน ระบบต้องแสดงข้อมูลผู้ใช้งานตามสิทธิ์ที่กำหนด
* **AC-ADMINUSER-02** เมื่อ Admin จัดการบัญชีผู้ใช้งาน ระบบต้องดำเนินการตามความสามารถที่มีอยู่ในระบบ
* **AC-ADMINUSER-03** เมื่อมีการดำเนินการกับข้อมูลผู้ใช้งาน ระบบต้องตรวจสอบสิทธิ์ของผู้ดำเนินการก่อน

## 5. Constraints

* การดำเนินการของผู้ดูแลระบบต้องเป็นไปตามสิทธิ์ของ Admin
* Admin ดูข้อมูลผู้ใช้งานได้เฉพาะข้อมูลตามสิทธิ์ที่ระบบกำหนด
* การจัดการบัญชีผู้ใช้งานอยู่ภายใต้ความสามารถที่มีอยู่ในระบบปัจจุบัน
* การจัดการข้อมูลบัญชีของผู้ใช้งานด้วยตนเองอยู่ในขอบเขตของ `010-user-account`
* การจัดการคำขอสมัครนักเขียนอยู่ในขอบเขตของ `012-writer-application`
* การบันทึกประวัติการดำเนินการอยู่ในขอบเขตของ `026-audit`

## 7. Open Questions

* ข้อมูลผู้ใช้งานใดที่ Admin สามารถดูได้ตามสิทธิ์ที่กำหนด และข้อมูลใดที่ไม่สามารถดูได้
* การจัดการบัญชีผู้ใช้งานตามความสามารถของระบบ ครอบคลุมการกระทำใดบ้าง
* Admin สามารถจัดการบัญชีของตนเองได้หรือไม่
* เมื่อบัญชีของผู้ใช้งานถูกจัดการโดย Admin ผลต่อสิทธิ์การใช้งานและข้อมูลของผู้ใช้งานนั้นเป็นอย่างไร
* ผู้ใช้งานได้รับการแจ้งเตือนเมื่อบัญชีถูกจัดการหรือไม่
