# Feature Specification: เรียกดูนิยายตามหมวดหมู่

**Feature ID:** `005-browse-category`
**Status:** Draft
**Source:** `docs/SRS.md`

## 1. Goal

ให้ Guest, Reader และ Writer สามารถเรียกดูนิยายตามหมวดหมู่ที่ต้องการได้

## 2. Scope

### In Scope

* แสดงหมวดหมู่ของนิยาย
* เลือกหมวดหมู่เพื่อเรียกดูนิยาย
* แสดงรายการนิยายที่อยู่ในหมวดหมู่ที่เลือก
* แสดงเฉพาะนิยายที่ผู้ใช้มีสิทธิ์เห็น

### Out of Scope

* การค้นหานิยายด้วยคำค้น
* รายละเอียดนิยาย
* การอ่านนิยาย
* แผนผังการอ่าน
* การบันทึกและอ่านต่อจากตำแหน่งเดิม
* ชั้นหนังสือ
* การติดตามนักเขียน
* การแจ้งเตือน
* การจัดการนิยายของ Writer
* การจัดการหมวดหมู่ของ Admin

## 3. Requirements

### R-CATBROWSE-01 — แสดงหมวดหมู่

ระบบต้องให้ผู้ใช้เรียกดูหมวดหมู่ของนิยายได้

**Traceability:** `FR-READ-02`

### R-CATBROWSE-02 — แสดงนิยายตามหมวดหมู่

เมื่อผู้ใช้เลือกหมวดหมู่ ระบบต้องแสดงรายการนิยายที่อยู่ในหมวดหมู่นั้น

**Traceability:** `FR-READ-02`

### R-CATBROWSE-03 — จำกัดนิยายตามสิทธิ์การเข้าถึง

ระบบต้องแสดงเฉพาะนิยายที่ผู้ใช้มีสิทธิ์เห็น

**Traceability:** `FR-READ-08`

## 4. Acceptance Criteria

* **AC-CATBROWSE-01** เมื่อผู้ใช้เปิดส่วนหมวดหมู่ ระบบต้องแสดงหมวดหมู่ที่สามารถเรียกดูได้
* **AC-CATBROWSE-02** เมื่อผู้ใช้เลือกหมวดหมู่ ระบบต้องแสดงรายการนิยายที่อยู่ในหมวดหมู่นั้น
* **AC-CATBROWSE-03** เมื่อหมวดหมู่ไม่มีนิยาย ระบบต้องไม่แสดงนิยายที่ไม่อยู่ในหมวดหมู่นั้น
* **AC-CATBROWSE-04** นิยายที่ผู้ใช้ทั่วไปไม่มีสิทธิ์เข้าถึงต้องไม่ปรากฏในรายการนิยายของหมวดหมู่

## 5. Constraints

* การเรียกดูหมวดหมู่ต้องไม่รวมการค้นหาด้วยคำค้น
* รายการนิยายต้องเคารพสิทธิ์การเข้าถึงของ Guest, Reader และ Writer
* การเลือกนิยายจากรายการสามารถนำไปยัง `006-novel-detail`
* การอ่านนิยายอยู่ในขอบเขตของ `001-read-novel`
