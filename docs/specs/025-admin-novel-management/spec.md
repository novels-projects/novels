# Feature Specification: การจัดการนิยายโดย Admin

**Feature ID:** `025-admin-novel-management`
**Status:** Draft
**Source:** `docs/SRS.md`

## 1. Goal

ให้ Admin ตรวจสอบนิยายที่เผยแพร่ในระบบ ค้นหาและตรวจสอบข้อมูลนิยาย ระงับการเผยแพร่ ดำเนินการปลดการระงับ และจัดการสถานะของนิยายตามเงื่อนไขของระบบ

## 2. Scope

### In Scope

* ตรวจสอบนิยายที่เผยแพร่ในระบบ
* ค้นหาและตรวจสอบข้อมูลนิยายตามความสามารถที่ระบบกำหนด
* ระงับการเผยแพร่นิยายที่อยู่ในสถานะเผยแพร่
* ดำเนินการปลดการระงับตามกระบวนการที่ระบบกำหนด
* จัดการสถานะนิยายหลังการระงับหรือปลดการระงับตามเงื่อนไขของระบบ

### Out of Scope

* การจัดการนิยายของนักเขียน
* การเผยแพร่นิยายโดยนักเขียน
* การจัดการหมวดหมู่โดย Admin
* การจัดการบัญชีผู้ใช้งานโดย Admin
* การส่งรายงานและการจัดการรายงาน
* การยื่นคำขอปลดการระงับ

## 3. Requirements

### R-ADMINNOVEL-01 — ตรวจสอบนิยายที่เผยแพร่

ระบบต้องให้ Admin ตรวจสอบนิยายที่เผยแพร่ในระบบได้

**Traceability:** `FR-ADMINNOVEL-01`

### R-ADMINNOVEL-02 — ค้นหาและตรวจสอบข้อมูลนิยาย

ระบบต้องให้ Admin ค้นหาและตรวจสอบข้อมูลนิยายตามความสามารถที่ระบบกำหนดได้

**Traceability:** `FR-ADMINNOVEL-02`

### R-ADMINNOVEL-03 — ระงับการเผยแพร่นิยาย

ระบบต้องให้ Admin ระงับการเผยแพร่นิยายที่อยู่ในสถานะเผยแพร่ได้

**Traceability:** `FR-ADMINNOVEL-03`

### R-ADMINNOVEL-04 — ดำเนินการปลดการระงับ

ระบบต้องให้ Admin ดำเนินการปลดการระงับตามกระบวนการที่ระบบกำหนดได้

**Traceability:** `FR-ADMINNOVEL-04`

### R-ADMINNOVEL-05 — จัดการสถานะนิยายหลังการระงับหรือปลดการระงับ

ระบบต้องจัดการสถานะนิยายหลังการระงับหรือปลดการระงับตามเงื่อนไขของระบบ

**Traceability:** `FR-ADMINNOVEL-05`

## 4. Acceptance Criteria

* **AC-ADMINNOVEL-01** เมื่อ Admin เปิดดูนิยายในระบบ ระบบต้องแสดงนิยายที่เผยแพร่
* **AC-ADMINNOVEL-02** เมื่อ Admin ค้นหาและตรวจสอบข้อมูลนิยาย ระบบต้องแสดงข้อมูลนิยายตามความสามารถที่ระบบกำหนด
* **AC-ADMINNOVEL-03** เมื่อ Admin ระงับการเผยแพร่นิยายที่อยู่ในสถานะเผยแพร่ ระบบต้องระงับการเผยแพร่ของนิยายเรื่องนั้น
* **AC-ADMINNOVEL-04** เมื่อ Admin ดำเนินการปลดการระงับ ระบบต้องดำเนินการตามกระบวนการที่ระบบกำหนด
* **AC-ADMINNOVEL-05** เมื่อมีการระงับหรือปลดการระงับนิยาย ระบบต้องจัดการสถานะของนิยายเรื่องนั้นตามเงื่อนไขของระบบ

## 5. Constraints

* การดำเนินการของผู้ดูแลระบบต้องเป็นไปตามสิทธิ์ของ Admin
* การระงับการเผยแพร่นิยายทำได้กับนิยายที่อยู่ในสถานะเผยแพร่
* สถานะของนิยายหลังการระงับหรือปลดการระงับต้องเป็นไปตามเงื่อนไขของระบบ
* การระงับการเผยแพร่นิยายเนื่องจากรายงานที่ได้รับการอนุมัติอยู่ในขอบเขตของ `023-report`
* การยื่นคำขอปลดการระงับอยู่ในขอบเขตของ `024-unban-appeal`
* การจัดการนิยายของนักเขียนอยู่ในขอบเขตของ `013-writer-novel-management`
* การเผยแพร่นิยายโดยนักเขียนอยู่ในขอบเขตของ `018-publish`
* การจัดการหมวดหมู่โดย Admin อยู่ในขอบเขตของ `021-admin-category`

## 7. Open Questions

* ความสามารถในการค้นหาและตรวจสอบข้อมูลนิยายของ Admin ครอบคลุมเงื่อนไขใดบ้าง
* เหตุผลที่ Admin ใช้ในการระงับการเผยแพร่นิยายต้องระบุหรือไม่ และมีข้อกำหนดใด
* กระบวนการปลดการระงับที่ระบบกำหนดประกอบด้วยขั้นตอนใดบ้าง
* สถานะของนิยายหลังการระงับการเผยแพร่และหลังการปลดการระงับเป็นอย่างไร และนิยายที่ถูกปลดการระงับต้องเผยแพร่ใหม่หรือไม่
* Admin สามารถระงับหรือปลดการระงับนิยายได้เมื่อใด และมีข้อจำกัดด้านจำนวนหรือเงื่อนไขหรือไม่
* ผู้ใช้งานและนักเขียนได้รับการแจ้งเตือนผลการระงับหรือปลดการระงับหรือไม่
* การดำเนินการของ Admin กับนิยายต้องถูกบันทึกเป็นประวัติการดำเนินการหรือไม่
