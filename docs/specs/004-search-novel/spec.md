# Feature Specification: ค้นหานิยาย

**Feature ID:** `004-search-novel`
**Status:** Draft
**Source:** `docs/SRS.md`

## 1. Goal

ให้ Guest, Reader และ Writer สามารถค้นหานิยายที่ต้องการจากระบบได้อย่างสะดวก

## 2. Scope

### In Scope

* ค้นหานิยายจากคำค้น
* แสดงรายการนิยายที่ตรงกับคำค้น
* แสดงเฉพาะนิยายที่ผู้ใช้มีสิทธิ์เห็น

### Out of Scope

* การเรียกดูนิยายตามหมวดหมู่
* การดูรายละเอียดนิยาย
* การอ่านนิยาย
* การดูแผนผังการอ่าน
* การบันทึกตำแหน่งการอ่าน
* การเพิ่มนิยายลงชั้นหนังสือ
* การติดตามนักเขียน
* การแจ้งเตือน
* การจัดการนิยายของ Writer
* การจัดการของ Admin

## 3. Requirements

### R-SEARCH-01 — ค้นหานิยาย

ระบบต้องให้ผู้ใช้ค้นหานิยายด้วยคำค้น และแสดงรายการนิยายที่ตรงกับคำค้น

**Traceability:** `FR-READ-01`

### R-SEARCH-02 — แสดงผลการค้นหา

เมื่อมีนิยายที่ตรงกับคำค้น ระบบต้องแสดงรายการผลการค้นหาให้ผู้ใช้สามารถเลือกนิยายที่ต้องการได้

**Traceability:** `FR-READ-01`

### R-SEARCH-03 — จำกัดผลการค้นหาตามสิทธิ์การเข้าถึง

ระบบต้องไม่แสดงนิยายที่ผู้ใช้ทั่วไปไม่มีสิทธิ์เข้าถึงในผลการค้นหา

**Traceability:** `FR-READ-08`

## 4. Acceptance Criteria

### AC-SEARCH-01

**Given** ผู้ใช้เข้าสู่หน้าค้นหานิยาย
**When** ผู้ใช้กรอกคำค้นและค้นหา
**Then** ระบบแสดงรายการนิยายที่ตรงกับคำค้น

### AC-SEARCH-02

**Given** มีนิยายที่ตรงกับคำค้น
**When** ระบบแสดงผลการค้นหา
**Then** ผู้ใช้สามารถเลือกนิยายจากรายการผลการค้นหาได้

### AC-SEARCH-03

**Given** ไม่มีนิยายที่ตรงกับคำค้น
**When** ผู้ใช้ค้นหา
**Then** ระบบแสดงสถานะว่าไม่พบผลการค้นหา

### AC-SEARCH-04

**Given** มีนิยายที่ยังไม่เผยแพร่หรือผู้ใช้ทั่วไปไม่มีสิทธิ์เข้าถึง
**When** ผู้ใช้ทั่วไปค้นหาด้วยคำค้นที่เกี่ยวข้อง
**Then** ระบบไม่แสดงนิยายดังกล่าวในผลการค้นหา

## 5. Constraints

* ผลการค้นหาสำหรับ Guest, Reader และ Writer ต้องเป็นไปตามสิทธิ์การเข้าถึงเนื้อหาของผู้ใช้
* นิยายที่ยังไม่เผยแพร่ต้องไม่ปรากฏในผลการค้นหาสำหรับผู้ใช้ทั่วไป
* การเลือกนิยายจากผลการค้นหาเพื่อดูรายละเอียดอยู่ใน Feature `006-novel-detail`
* การอ่านนิยายอยู่ใน Feature `001-read-novel`
